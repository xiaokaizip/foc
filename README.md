
#### 概述
- 在本仓库中，将存放关于我学习FOC的软硬件资料。
- 硬件包括stm32版本的FOC和hpm版本的hpm，以及单独的FOC驱动。
- 软件包括FOC的代码，已经相对应的上位机软件的代码
#### 硬件设计
##### 基于STM32G4的FOC设计
- 电机参数：
  - 额定电流：1A
  - 峰值电流：2.1A
  - 相电阻：2.25Ω
  - 相电感：1.67uH
  - 鉴于该电机的电流比较小，所以驱动小型化也是很有可能性的。

- 主控：STSPIN32G4
  - 该主控集成了一片STM32G474、三相半桥的驱动、buck、ldo和运算放大器，所以只需要一个主控再加上三个半桥就能实现。
  
- 通讯接口：
  - 由于驱动板的尺寸比较小，所用的通讯接口也有限，在只接can接口和串口。
  - can 芯片使用Ti的TCAN1044VDDFR，能实现最高8M的速率。
- 编码器
  - 编码器使用MT6825，虽然很贵但是新能很高。
- 由于体积较小，接口需要使用较小的接口，使用sh1.0的座子作为接口。
- led使用NCD3010YCB1，能对侧面发光。
